# Fontes PP Fragment

O site já está configurado para usar PP Fragment Sans (títulos) e PP Fragment Glare (destaque).
Enquanto os arquivos não estiverem aqui, entram Instrument Sans/Serif como fallback.

Para ativar, coloque nesta pasta, em .woff2:
- PPFragment-SansRegular.woff2
- PPFragment-SansExtraBold.woff2
- PPFragment-GlareRegular.woff2

Atenção: este repositório é público. Só suba os arquivos se a licença da Garten
(Pangram Pangram) incluir uso web; a licença desktop normalmente não cobre.
